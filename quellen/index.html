Quellen und Lizenzen

Alle fachlichen Aussagen dieser Seiten stützen sich auf die folgenden Dokumente. Stand der Prüfung: 27.10.2026. Die Datei quellen.md im Repository enthält dieselbe Liste mit den genauen Fundstellen.

Standards und Leitfäden

  • VHitG-Arztbrief-Leitfaden v1.50 (HL7 Deutschland): Definition von CDA, Kerneigenschaften (Kapitel 3.2 bis 3.4), Level (6.2), Kopfelemente mit Kardinalitäten, Dokumenttyp- und Abschnittscodes.
  • HL7 Deutschland, Downloads: Einordnung des VHitG-Leitfadens v1.50 als „Arztbrief 2006“, abgelöst durch den „Arztbrief 2014/2015“.
  • HL7 International, Consolidated CDA (C-CDA) v5.0.0, IG Home: Dokumenttypen und Zweck von C-CDA.
  • HL7 International, FHIR Documents: Aufbau von FHIR-Dokumenten (Bundle, Composition) und Rolle von DocumentReference.

eArztbrief

  • KBV, Richtlinie elektronischer Brief (in Kraft seit 17.05.2024): Inhalt des elektronischen Briefes (PDF/A und XML nach VHitG v1.50, body darf leer sein, qualifizierte Signatur).
  • KBV, eArztbrief: Versand, Empfang und technische Voraussetzungen: Versand über KIM, Empfangspflicht seit 30.06.2024.

Browser und XSLT

  • Chrome for Developers, Removing XSLT for a more secure browser: Zeitplan der Entfernung von XSLT: Chrome 158 am 17.11.2026, Chrome 176 am 17.08.2027. Der Zeitplan kann sich ändern; maßgeblich ist die Seite von Chrome.

Beispieldaten

  • Drei Beispiele stammen aus HL7/C-CDA-Examples auf GitHub (CC0 1.0), Commit ad5007abd912a45bbd04ce96e871c70954c2b2c2. Die LICENSE-Datei des Repositories ist „CC0 1.0 Universal“. Die README verweist zusätzlich auf die HL7-GOM (Abschnitt 09, Geistiges Eigentum) für eingereichte Beispiele. Jede Datei trägt den Hinweis, dass sie die Daten einer fiktiven Person enthält. Geändert wurde nur eine E-Mail-Adresse (ersetzt durch isabella.jones@example.org).
  • Die zwei deutschen Beispiele sind frei erfunden und stehen unter der MIT-Lizenz des Projekts. Sie sind nicht gegen einen Leitfaden oder Schematron geprüft.
  • Codes: Die Beispiele verwenden LOINC-Codes. LOINC ist ein Urheberrecht des Regenstrief Institute, Inc.; Informationen unter loinc.org. Der Viewer enthält keine LOINC-Tabelle, nur die Codes in den Beispielen.

Software

Der Viewer läuft ohne Bibliotheken von Dritten. Für die automatischen Tests im Repository wird jsdom (MIT-Lizenz) verwendet; es gehört nicht zur ausgelieferten Seite. Details: THIRD-PARTY-LICENSES.

Fehler melden

Stimmt eine Aussage nicht mehr, oder zeigt der Viewer eine Datei falsch an? Ein Hinweis im Issue-Tracker auf GitHub hilft. Bitte hängen Sie keine echten Patientendaten an.
